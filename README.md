# codelibs/homebrew-tap

Homebrew tap for [CodeLibs](https://github.com/codelibs) tools.

## Installation

```bash
brew tap codelibs/tap
brew install <formula>
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `fessctl` | CLI tool to manage [Fess](https://github.com/codelibs/fessctl) via the admin API |

## Supported Platforms

- macOS arm64 (Apple Silicon)
- macOS x86_64 (Intel)
- Linux x86_64 (Linuxbrew)

## Updating Formulae

Formulae are auto-bumped via PRs from each tool's release workflow. PRs run through CI (`.github/workflows/ci.yml`) before being merged by a maintainer.
